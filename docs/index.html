Buchproduktion mit n8n

Sieben Workflows mit zusammen 200 Nodes, von der Themenrecherche über das Manuskript bis zum druckfertigen Cover. So, wie sie produktiv laufen, mit jedem Prompt und jeder Zeile Code.

Ersetzt sind nur IDs, Adressen und Autorennamen. Klick auf einen Node zeigt seinen Inhalt, ziehen verschiebt die Fläche, das Mausrad zoomt. Quelltext und README auf GitHub
